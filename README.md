# FLAP ⚽ 出場選手情報サポート

試合当日に使う、選手の出場時間を管理するシンプルなWebアプリです。
ブラウザだけで動作し、インストールは不要です。

**公開ページ：** https://manjiro-jpn.github.io/FLAP/

## 使い方

1. **選手登録**（index.html）
   - 選手名を入力して「登録」。重複登録はできません。
   - 登録した選手は次回以降も残ります。

2. **フェーズ入力**（phase.html）
   - 試合を4つのフェーズ（前半 0-15／前半 15-30／後半 0-15／後半 15-30、各15分）に分けて、各フェーズの出場メンバーを選びます。
   - フォーメーションは 1-4-2-3-1／1-4-4-2／1-3-5-2／1-3-4-3 から選択可能。
   - 同じ選手を同じフェーズで重複選択すると警告が出ます。
   - 「前フェーズコピー」で前のフェーズのメンバーを引き継げます。
   - 入力が終わったら「保存」を押してください。

3. **結果・出場時間**（result.html）
   - 選手ごとの出場フェーズと合計出場時間（バー表示つき）を確認できます。
   - フェーズ間の交代（IN／OUT）とシステム変更も表示されます。
   - 「結果をコピー」で出場時間の一覧をテキストでコピーできます。

## データについて

- データはブラウザの **localStorage** に保存されます。サーバーへの送信はありません。
- 端末やブラウザを変えるとデータは引き継がれません。
- 選手登録ページの「オールクリア」で全データを削除できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 選手登録 |
| `phase.html` | フェーズ入力（フォーメーション・メンバー選択） |
| `result.html` | 結果・出場時間の表示 |

## 表示について

- スマートフォンでの利用を想定したレイアウトです。
- 端末のダークモード設定に合わせて、暗い配色にも自動で切り替わります。
